# Task Prompt Template (for low token usage)

Use this exact structure for each task:

## Goal

One sentence describing the expected outcome.

## Allowed files

List only files/directories that may be edited for this task.

## Constraints

- Keep changes minimal and scoped.
- Do not modify unrelated files.
- Do not expand scope beyond this task.

## Required checks

List exact commands to run for this task only.

## Definition of done

- What must be true to consider this task complete.
- What must be demonstrated in output/logs/tests.

## Out of scope

Explicitly list what should **not** be done in this task.
